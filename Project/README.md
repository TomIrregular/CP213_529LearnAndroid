**Tom Weasley's OVERGRILLED 🥩**  
เกม Casual/Arcade สำหรับ Android เล่นคนเดียว สวมบทบาทเป็นเจ้าของร้านสเต๊กในมหาวิทยาลัยแห่งหนึ่ง คุณจะต้องรับคำสั่งของนักศึกษาของแต่ละคณะที่มีความชอบแตกต่างกันไป และพยายามทำอาหารให้ได้ตามความต้องการของพวกเขาเพื่อให้ได้เงินมาจ่ายค่าเช่าร้าน คุณสามารถไปได้ไกลถึงวันที่เท่าไหร่  

***Tech Stack***  
+ Language: Kotlin  
+ UI Framework: Jetpack Compose  
+ Architecture: MVVM  
+ Local Storage: Room  
+ State Management: StateFlow / LiveData
  
***Features***  
+ นักศึกษาจากหลายคณะกับตารางอาหารของตัวเอง : ระบบสุ่มคำสั่งซื้อจากตารางอาหารของนักศึกษาที่มีบุคลิกและกล่องข้อความของตัวเอง  
+ ระบบทำอาหาร : กดประเภทเนื้อมาอยู่บนเตาและเร่งไฟให้ตามประเภทที่ลูกค้าสั่ง สามารถกดเนื้อบนเตาเพื่อพลิกด้าน และกดที่เครื่องเคียงอย่างซอสและมันบดเพื่อทำให้เมนูสมบูรณ์แบบ  
+ ความยากที่เพิ่มขึ้น : ระบบ Quota รายวันที่เพิ่มขึ้นเรื่อยๆ ในแต่วัน และลูกค้าหน้าใหม่ที่มาทุกวันทำให้คุณต้องจำเมนูเพิ่ม  
+ ทำความรู้จักและจดจำคำพูดประจำตัวละครเพื่อทำอาหารให้ได้ไวและถูกต้องที่สุดเท่าที่จะทำได้
+ กราฟิก UI ที่วาดเองด้วยมือ
