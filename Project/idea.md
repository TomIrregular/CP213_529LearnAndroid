Tom Weasley's OVERGRILLED เป็นภาคต่อของโปรเจคเกมวิชา OOP ชื่อ Overboiled นำมาลงใน Android ซึ่งเป็นเกมแนว Arcade Casual เปิดร้านสเต๊กในมหาวิทยาลัยแห่งหนึ่ง ให้ผู้เล่นรับคำสั่งทำสเต๊กและทำให้ตรงคำสั่งให้ได้ดีที่สุดเพื่อให้ได้เงินให้ถึงโควต้าของวันนั้นซึ่งก็จะเพิ่มขึ้นเรื่อยๆ โดยเป้าหมายของเกมให้ไปถึงวันที่ไกลที่สุดเท่าที่จะทำได้  

**Features:**  
- NPC ลูกค้าที่สุ่มเมนูที่ต้องการตามเซ็ทที่กำหนดไว้ในประเภทนั้นๆ (NPC เด็กวิทย์คอมอาจสั่งมันบดมาด้วย / NPC เด็กอักษรอาจสั่งสเต๊กปลาหรือไก่ แต่ไม่เคยสั่งวัว โดยสามารถทราบได้จากชุดบทสนทนาที่ปรากฎ) หากผู้เล่นจำลูกค้าประเภทนั้นและคำพูดได้ ก็สามารถทำอาหารเสร็จก่อนบทสนทนาได้  
- การทำอาหารจะเป็นการกดประเภทเนื้อมาอยู่บนเตาและเร่งไฟให้ตามประเภทที่ลูกค้าสั่ง สามารถกดเนื้อบนเตาเพื่อพลิกด้าน (หากลูกค้าสั่ง Well-done เนื้อจะต้องเร่งไฟปานกลางบนสองฝั่ง / หากลูกค้าสั่ง Medium-Rare ด้านหนึ่งจะต้องเร่งไฟปานกลางและอีกด้านไฟอ่อน)  
- เพิ่มของข้างเคียงตามที่ลูกค้าสั่งได้ (มันบด / ซอสพริก / ซอสเกรวี่)
